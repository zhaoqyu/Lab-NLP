# Value Alignment Evaluation Suite

This directory encompasses the final, definitive evaluation suite for the Value Alignment project. Our evaluation infrastructure is strictly designed to decouple the generation/training processes from the evaluation metrics. It consumes the raw output artifacts (JSON result matrices) generated by the Data Pipeline and Model Training teams, applying rigorous statistical and comparative analyses to verify behavioral alignment.

## Core Evaluation Principles
1. **Decoupled Verification:** Evaluation scripts do not train models; they ingest the raw output logs (`.json` files) from the trained checkpoints to ensure uncompromised metric calculation.
2. **Strict Error Handling:** Scripts utilize comprehensive `logging` and JSON schema validation.
3. **Statistical Rigor:** All variance, mean shifts, and target probability gains are calculated using standard scientific libraries over the full evaluated populations.

## Script Usage & Architecture

### 1. Comparative KVS Intrinsic Analysis

**`evaluation/compare_kvs_results.py`**
- **Purpose:** Ingests the JSON scores produced by the training runs. It computes population-level differences to verify if the model successfully mitigated toxic behaviors while remaining stable on unrelated metrics.
- **Metrics Extracted:**
  - *Target Value Rating Drop:* Ensures alignment against toxic inputs.
  - *Other Values' Variance:* Calculates deviation across benign datasets to prevent catastrophic forgetting.
- **Usage (Consuming Teammate Outputs):**
  ```bash
  python evaluation/compare_kvs_results.py \
      --base ../Model\ and\ Training/results/kvs_base_scores.json \
      --trained ../Model\ and\ Training/results/kvs_hypo_scores.json \
      --target-values Security_personal
  ```

### 2. Probability Gain Extrinsic Analysis

**`evaluation/evaluate_aita_probability_gain.py`**
- **Purpose:** Processes the raw output logits generated over the AITA scenarios to compute `P_gain(S)`.
- **Methodology:** It operates dynamically over standard judgment tokens (e.g., "NTA"), enforcing a strict zero-gradient pass to calculate purely deterministic probability distributions.
- **Usage:**
  ```bash
  python evaluation/evaluate_aita_probability_gain.py \
      --base-model qwen2.5-7b \
      --trained-model ../Model\ and\ Training/checkpoints/hypo/final \
      --test-file ../dataset/aita_test.jsonl
  ```

### 3. MACHIAVELLI Integration

**`setup_machiavelli.sh` & `evaluation/machiavelli_hf_agent_template.py`**
- **Purpose:** Prepares the environment to benchmark against sophisticated power-seeking behavior metrics, translating our LLM API to standard Gym interfaces.
